# Bhoomitra

Bhoomitra is a farmer-focused frontend for crop tracking and field management.
The demo includes a farmer sign-in screen, crop dashboard, weather and reminder
cards, a locally saved crop log, advisory feedback, and a QR-based harvest
traceability view.

## Run the frontend

```powershell
cd frontend
npm install
npm run dev
```

The app is frontend-only for now. Demo crop-log entries and advisory feedback
are saved in the browser's local storage.
